# Ứng dụng "Hiểu Nhau"

Ứng dụng web giúp cha mẹ và con cái hiểu nhau hơn thông qua AI.

## Cách chạy
Vì lý do dung lượng đĩa hiện tại trên máy đang đầy (0 bytes free), tôi đã xây dựng ứng dụng này dưới dạng một file HTML duy nhất cực kỳ tối ưu, không cần cài đặt `node_modules`.

1. Mở file `index.html` trực tiếp bằng trình duyệt.
2. Trải nghiệm demo đầy đủ các tính năng:
   - Trang chủ (Landing Page)
   - Tạo/Tham gia phòng
   - Giao diện trả lời câu hỏi
   - Báo cáo kết quả AI chi tiết

## Công nghệ sử dụng
- HTML5, Vanilla CSS (Premium design system)
- Vanilla JavaScript (State management & Transitions)
- Lucide Icons (CDN)
- Google Fonts (Inter & Outfit)
